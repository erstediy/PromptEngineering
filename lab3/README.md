# Отчёт по лабораторной работе № 3 «Мой агент»

## Выполнили

- **Крижановский Данил** — придумал идею игрового мастера для короткой партии и тему приключения «Последний огонь маяка», подготовил сценарий, реализовал агента и игровые правила, проверил прохождение.
- **Codex (ИИ-ассистент)** — реализовал интерфейс, оформил материалы.

## Мотивирующий абзац (Project Statement)

«Последний огонь маяка» — текстовое приключение для 1–3 игроков за одним экраном. Маяк погас, а из тумана доносится колокол затонувшего корабля. Как добраться до башни и что делать со звонарём, решают игроки. Игрок описывает решение своими словами, мастер связывает его с правилами, а последствия остаются в партии до финала.

## Использование ИИ

Во время партии роль мастера исполняет DeepSeek V4.1 Flash через Yandex AI Studio. На каждом ходу агент в LangGraph получает действие игрока, историю диалога и состояние отряда. Инструмент `read_scene` позволяет ему обратиться к заметкам о текущей сцене. Через `play` агент передаёт выбранное действие игровым правилам. Программа проверяет инвентарь, при необходимости бросает кубик и возвращает исход. На его основе мастер рассказывает, что произошло. [Промпт мастера и инструменты](master.py) · [Игровые правила](game.py)

## Результаты

Игроки выбирают героев и проходят три локации. На игровом столе рядом с рассказом мастера видны здоровье отряда, общие вещи и журнал бросков. В демонстрации записаны две партии по одному сценарию.

| Прохождение | Как герои пересекли затопленный проход | Чем закончилась партия |
|---|---|---|
| «Огни памяти» | Мара прошла по поручню. На d20 выпало 15, бонус за ловкость дал 18 при пороге 10. | Ива вернула звонарю дощечку с именем судна. Он вспомнил команду, и маяк загорелся. |
| «Берег спасён» | Герои забрали сухой фитиль и закрепили верёвку. Отряд прошёл без броска, верёвка осталась на поручне. | Ива зажгла лампу найденным фитилём. Свет вернулся, но колокол в тумане по-прежнему слышен. |

## Выводы

Свободный ввод даёт игрокам возможность предложить свой способ решить задачу. Чтобы мастер мог последовательно описать последствия, ему нужна точная запись уже совершённых действий. Хранение состояния партии в коде помогает согласовать рассказ с тем, что игрок видит на экране. Если отряд оставил верёвку в проходе, она исчезает из инвентаря и остаётся недоступной в следующей сцене.

**Краткий запуск.** В каталоге `lab3` с Python 3.13 выполнить `python -m pip install -r requirements.txt`, заполнить `.env` по [образцу](.env.sample) ключом и идентификатором каталога Yandex AI Studio, затем выполнить `python app.py` и открыть [игровой стол](http://127.0.0.1:18743/).
